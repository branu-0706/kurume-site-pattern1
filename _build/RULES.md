# 久留米興業サイト 制作ルール（公開前チェック）

公開・push・確認用ページの更新の前に、必ず `node _build/qa.js` を実行し「OK」になってから出す。

## 1. 写真
- 同じ写真をサイト内で2回以上使わない（ページをまたいでも不可）。HERO・カード・背景画像・アバターも数える。
  - 「サイト」の単位：パターン①×デザイン①（6ページ）、パターン②×デザイン①（6ページ）、比較用TOP 4案（各1ページ）。
  - 比較用TOPは同じ構成パターンのTOPと同じ写真を使ってよい（デザインだけを比べるため）。ただし1ページの中での重複は不可。
  - トリミング違いの同じ写真（ceo と ceo-wide、field-sidewalk2 と field-team-back、office-pc と office-pc-wide）も同じ写真として数える。
- 写真が足りないときは使い回さず、写真なしのカード（`.link-card.no-media`）や文字だけのレイアウトにする。
- 作業員（現場職）の個人紹介には、顔が見えない作業中の写真を使う。
- 代表の写真は、代表インタビュー資料の写真から使う。
- 工事黒板に他社名が写る写真は、自社施工の実績として使わない。

## 2. 表記
- 画面に出典・情報源を書かない（「求人票より」「採用ブログ」「出典」「公式サイトの掲載表記」など）。根拠の管理は確認用ページ側で行う。
- 制作メモ（CMS連携予定など）は公開画面に出さず、`.review-note`（確認用のみ表示）にする。
- 見出しは自然な日本語にする。体言止めや倒置で意味が通りにくくならないか読み返す。
  - 例：×「一日には、いくつもの役割がある。」→ ○「1日の中でも、いくつもの役割がある。」
  - 例：×「夏も現場へ」→ ○「夏の暑さの対策」（大変さを書くときは、会社の対策とセットにする）
- 「1日」「一日」は「1日」に統一する。

## 3. コントラスト
- 本文は背景とのコントラスト比4.5以上、大きい文字（24px以上、または18.6px以上の太字）は3以上。
- 濃い背景（`.navy-band` など）の上に白いカードを置くときは、カード内の文字色を必ず濃色に戻す。
- 薄いグレーの文字は使わない。補足文も `#4d5c70` 程度より濃くする。

## 4. 自動チェック（qa.js）で見ているもの
写真の使い回し（サイトごと・ページ内）／コントラスト不足（1440px・390px）／表記NGワード／横スクロール（1440・1024・390・360・320px）／画像切れ／ページ内・ページ間のリンク切れとアンカー切れ／H1の数／JSエラー

## 5. 構成×デザインの比較
- 既存のパターン①×デザイン①のURL・HTMLは変えない（比較切替の読み込み2行と html の data 属性だけを追加）。
- デザインごとのCSSは `assets/compare/*.css` と `assets/p2.css` に分け、`[data-structure][data-design]` にスコープする。単なる色違いにせず、レイアウト・写真配置・文字組み・動きを変える。
- 比較切替は `assets/compare/switcher.js / switcher.css` の独立部品。CMS移植時は読み込み2行を消すだけで外せる状態を保つ。
- 同じ構成パターンのデザイン②・③は `_build/cmp_copy.py` の同じ文章・写真・リンクを使う。
