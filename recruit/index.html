MESSAGE FROM CEO 代表メッセージ

最初から、何でもできる
必要はありません。

一人ひとりが、自分の仕事を増やしていける会社に。

私自身、18歳でこの業界に入り、現場で仕事を覚えるところから始めました。一度は会社を離れましたが、その後また戻り、現場、管理、取引先とのやり取りを経験してきました。今は、働く人それぞれに違う大変さがあることを忘れずに、会社をつくっていきたいと思っています。

最初から何でもできる人だけを求めているわけではありません。分からないことを聞き、自分でも考え、少しずつできることを増やしてほしい。昨日できなかったことができるようになる。その積み重ねを大切にしたいと思っています。

仕事だけが人生のすべてではありません。だからこそ、久留米興業で過ごす時間が、その人の技術や経験になり、いつか「ここで働いて良かった」と思ってもらえる会社を目指します。

CAREER PATH 久留米興業で歩むキャリア

仕事を覚えるほど、
任される仕事が変わっていく。

同じ「未経験」でも、スタートの仕方や成長の道筋は職種によって違います。ここでは、実際のヒアリングをもとに、久留米興業で仕事を覚えていく過程をご紹介します。年数は標準的な到達保証ではなく、仕事の習得に応じた目安です。

営業職現場職
SALES

営業職

  1. 入社初日〜1週間

    仕事の入口を知る

    PCの設定など準備をした後、先輩に同行し、取引先や現場を訪問。複数の先輩の仕事を見ながら、業界特有の用語や仕事の流れに触れます。

  2. 入社〜3か月

    現場と人の関係を覚える

    先輩同行を基本に、現場でどんな作業が行われ、誰がどの役割を担うのかを学びます。

  3. 3か月以降

    少しずつ任される範囲を広げる

    現地調査、材料の運搬、取引先との会議、緊急対応の補助などに関わり、できることを増やします。

  4. 半年〜1年を目指す姿

    現場と取引先の橋渡しに

    翌日の段取りの補助や社内外の情報共有に携わり、現場と営業をつなぐ役割を担うことを目指します。

  5. その先

    案件を任せられる人へ

    見積、取引先との打ち合わせ、金銭・外注手配の調整、資格取得などを通して、案件を主体的に進める力を身につけます。

FIELD WORK

現場職

  1. 入社直後

    まずは現場を見る・知る

    入社初期から現場へ入り、作業の流れ、安全上の注意点、道具や機械の使われ方を知るところから始まります。

  2. 仕事を覚える段階

    一つずつできることを増やす

    周囲の作業を見ながら、補助的な作業や道具の扱いを覚え、担当できる範囲を広げていきます。

  3. 経験を積んだ先

    次の工程を考えられる人へ

    「この後に何が必要か」を見ながら動けることが、成長を測る一つの目安になります。

  4. さらに先

    資格や現場の役割を広げる

    重機に関わる資格や、現場の副責任者に近い業務を目指せる可能性があります。個人の適性・取得要件により異なります。

年数だけではなく、

Q&A よくある質問

応募前に、気になること。

仕事内容

建設業の経験がなくても応募できますか？

営業職は異業種からの応募を想定しており、入社後は先輩社員に同行しながら仕事を覚えていきます。現場職も、経験や適性に応じて仕事を覚えていただく方針です。応募資格は各募集要項をご確認ください。

営業職はいきなり一人で取引先を担当しますか？

初日から案件を任せるのではなく、入社当初は先輩社員への同行から始める予定です。最低3か月程度は同行を基本とし、習熟度に応じて役割を広げていきます。

成長・評価

どのような仕事ぶりが評価されますか？

職種や経験年数によって異なります。学ぶ姿勢、現場との連携、できるようになった作業や業務、資格、取引先・現場からの評価などを大切にしています。

仕事に必要な資格は取得できますか？

資格取得を支援する制度があります。支援対象となる資格、費用負担、取得条件は募集要項・面談時にご確認ください。

働き方・応募

現場職の仕事は体力的に大変ですか？

早朝からの移動や夏場の暑さなど、現場ならではの負担があります。仕事内容や安全対策を含め、労働環境ページで紹介しています。

遠方からの応募は可能ですか？

個室寮の案内があります。空室や費用、入寮条件、勤務地との通勤については応募前にお問い合わせください。

応募前に仕事内容を確認する方法はありますか？

現場見学をご案内しています。実施可能な日程やオンライン面談の可否は、採用担当と調整のうえご案内します。

入社までの選考の流れは？

【要確認】応募受付 → 連絡 → 書類確認 → 面談 → 結果連絡 の実際の運用を確定して記入します。
